# PATRIMONIO v2.1.1

Correcciones de confort móvil:

- Los campos de monto ahora formatean con puntos mientras se escribe: `1200000` → `1.200.000`.
- También se formatean fórmulas simples: `=1200000+500000` → `=1.200.000+500.000`.
- Se corrigió la ubicación del botón `+` para que no se solape con los botones discretos de IA/Excel/JSON en Inicio.
- Se mantiene toda la funcionalidad de v2.1: historial, exportación JSON, exportación Excel, análisis IA, obligaciones por banco, fondo personalizable y PWA.

## Uso
Abrir `index.html` o subir todo el contenido al root de GitHub Pages.
